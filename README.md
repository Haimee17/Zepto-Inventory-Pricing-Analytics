# Zepto Inventory & Pricing Analytics

## Project Overview

This project analyzes Zepto product inventory and pricing data using
PostgreSQL, SQL, and Microsoft Power BI.

The objective is to understand product pricing, discounts, inventory
availability, estimated revenue, and category-wise inventory patterns.

## Technologies Used

- PostgreSQL
- SQL
- Microsoft Power BI
- DAX

## SQL Analysis

The project answers the following business questions:

1. Find the top 10 best-value products based on discount percentage.
2. Find products with high MRP but currently out of stock.
3. Calculate estimated revenue for each category.
4. Find products where MRP is greater than ₹500 and discount is less than 10%.
5. Identify the top 5 categories with the highest average discount.
6. Find the price per gram for products weighing 100g or more.
7. Group products into Low, Medium, and Bulk weight categories.
8. Calculate total inventory weight for each category.

## Power BI Dashboard

The interactive dashboard provides:

- Total SKUs
- Total Categories
- Available Quantity
- Estimated Revenue
- Stock Availability
- Average Discount by Category
- Top 10 Products by Discount
- High-MRP Out-of-Stock Products
- MRP vs Discounted Selling Price
- Category-wise Inventory Analysis
